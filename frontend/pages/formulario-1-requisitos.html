Requisitos 'Cadastro de Endereço'

Campos

Observação: Todos os campos obrigatórios devem ser identificados com asterisco (*) no label.

Logradouro*

  • Requisito: Deve permitir digitar texto (rua, avenida, etc.).
  • Critérios de aceite:
    • Campo não pode estar vazio.
    • Não deve conter apenas números.
    • Exibir mensagem de erro em modal se não atender às regras.
    • Mensagem exibida: “Preencher corretamente o campo Logradouro, dúvida entrar em requisitos!”

Número*

  • Requisito: Deve permitir apenas números.
  • Critérios de aceite:
    • Campo não pode estar vazio.
    • Não deve aceitar letras ou caracteres especiais.
    • Mensagem exibida: “Preencher corretamente o campo Número, dúvida entrar em requisitos!”

Complemento

  • Requisito: Campo opcional para informações adicionais.
  • Critérios de aceite:
    • Pode estar vazio.
    • Deve aceitar texto livre.

Bairro*

  • Requisito: Deve permitir texto (mínimo 3 caracteres).
  • Critérios de aceite:
    • Campo não pode estar vazio.
    • Não deve aceitar números isolados.
    • Mensagem exibida: “Preencher corretamente o campo Bairro, dúvida entrar em requisitos!”

Cidade*

  • Requisito: Deve permitir texto (mínimo 3 caracteres).
  • Critérios de aceite:
    • Campo não pode estar vazio.
    • Não deve aceitar números isolados.
    • Mensagem exibida: “Preencher corretamente o campo Cidade, dúvida entrar em requisitos!”

Estado*

  • Requisito: Deve permitir apenas 2 letras correspondentes a uma UF válida.
  • Critérios de aceite:
    • Campo não pode estar vazio.
    • Deve aceitar letras maiúsculas ou minúsculas, convertendo automaticamente para maiúsculas.
    • Deve validar se a UF existe na lista oficial de estados brasileiros.
    • Mensagens exibidas: - “Preencher corretamente o campo Estado, dúvida entrar em requisitos!” - “UF inválida! Preencher corretamente o campo Estado, dúvida entrar em requisitos!”

CEP*

  • Requisito: Deve permitir apenas números (8 dígitos).
  • Critérios de aceite:
    • Campo não pode estar vazio.
    • Não deve aceitar letras ou caracteres especiais.
    • Campo aplica máscara automática no formato 00000-000.
    • Mensagem exibida: “Preencher corretamente o campo CEP, dúvida entrar em requisitos!”

Botões

Salvar

  • Requisito: Executa a validação dos campos e simula cadastro de endereço.
  • Critérios de aceite:
    • Se todos os campos obrigatórios estiverem corretos, exibir mensagem de sucesso em modal.
    • Mensagem exibida: “Endereço cadastrado com sucesso!”.
    • Não deve permitir salvar com campos obrigatórios vazios.
    • Após sucesso, desabilitar e limpar os campos, além de desativar o botão “Salvar”, até que o usuário clique em “Limpar Endereço”.
    • Cadastro deve ser armazenado no localStorage e exibido pelo botão QA.

Voltar

  • Requisito: Redireciona para a tela Home.
  • Critério de aceite: Ao clicar, deve carregar home.html.

Requisitos

  • Requisito: Redireciona para a tela de requisitos.
  • Critério de aceite: Ao clicar, deve carregar formulario-1-requisitos.html.

QA - Ver Endereço Salvo

  • Requisito: Exibe os dados do endereço armazenados no localStorage.
  • Critério de aceite: Ao clicar, deve mostrar em modal os dados salvos ou mensagem de ausência.

QA - Limpar Endereço

  • Requisito: Remove o endereço armazenado no localStorage.
  • Critérios de aceite:
    • Ao clicar, deve apagar os dados, limpar os campos e ocultar novamente os botões de QA.
    • Após limpar, os campos e o botão “Salvar” devem ser reabilitados.
    • A modal deve conter botão OK para fechar.

Acessibilidade

  • Avatar VLibras deve estar disponível em todas as páginas.
  • Botão de Leitura em Áudio deve estar disponível no canto superior direito.
  • Todos os botões devem possuir atributos aria-label descritivos.
  • Mensagens de erro e sucesso devem ser anunciadas pelo recurso de áudio.
  • Todos os modais devem ser acessíveis por teclado, leitura em áudio e VLibras.
