Requisitos 'Novos Campos'

Campos

Upload de Arquivo (PDF)

  • Requisito: Usuário deve selecionar um arquivo em formato PDF.
  • Critérios de aceite:
    • Campo obrigatório.
    • Somente arquivos com extensão .pdf são aceitos.
    • Mensagem exibida (erro): “Campo para arquivo PDF, dúvidas entrar em requisitos!”.
    • Mensagem exibida (sucesso): “Arquivo selecionado corretamente!”.
    • Feedback visual: borda vermelha para erro, verde para sucesso.

Seleção de País, Estado e Cidade

  • Requisito: Usuário deve selecionar um país, um estado e uma cidade.
  • Critérios de aceite:
    • Todos os três campos são obrigatórios.
    • Não deve permitir envio se algum campo estiver vazio.
    • As opções devem aparecer organizadas em hierarquia (País → Estado → Cidade).
    • Mensagem exibida (erro): “Preencha corretamente os campos de País, Estado e Cidade.”
    • Feedback visual: cada campo individual recebe borda vermelha se vazio, verde se preenchido.
    • Modal de sucesso exibida imediatamente quando os três campos forem preenchidos corretamente.

Validações e Feedback

  • Validação imediata ao selecionar arquivos: se o tipo for incorreto, abrir modal e marcar campo em vermelho.
  • Validação imediata ao selecionar País/Estado/Cidade: cada campo recebe feedback individual.
  • Validação no envio: se houver campos inválidos, abrir modal genérica “Existem campos inválidos. Revalide os campos destacados em vermelho.”
  • Campos inválidos permanecem destacados em vermelho até correção.
  • Campos válidos ficam destacados em verde.
  • Após envio bem-sucedido, todos os campos são limpos e resetados, incluindo a remoção das classes de erro/sucesso.

Botões

Enviar

  • Requisito: Executa a validação dos campos e simula envio do formulário.
  • Critérios de aceite:
    • Se todos os campos obrigatórios estiverem corretos, exibir mensagem de sucesso.
    • Mensagem exibida: “Formulário enviado com sucesso!”.
    • Não deve permitir envio com campos obrigatórios vazios ou arquivos inválidos.

Voltar

  • Requisito: Redireciona para a tela Home.
  • Critério de aceite: Ao clicar, deve carregar home.html.

Requisitos

  • Requisito: Redireciona para a tela de requisitos.
  • Critério de aceite: Ao clicar, deve carregar formulario-3-requisitos.html.

Acessibilidade

  • Avatar VLibras deve estar disponível em todas as páginas.
  • Botão de Leitura em Áudio deve estar disponível no canto superior direito.
  • Todos os botões devem possuir atributos aria-label descritivos.
  • Mensagens de erro e sucesso devem ser anunciadas pelo recurso de áudio.
  • Todos os modais devem ser acessíveis por teclado, leitura em áudio e VLibras.
