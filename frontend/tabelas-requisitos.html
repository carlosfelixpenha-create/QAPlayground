Requisitos 'Tela de Tabelas'

Tabela Simples

  • Requisito: Exibir dados estáticos com interação básica.
  • Critérios de aceite:
    • A tabela deve exibir corretamente todas as linhas e colunas.
    • Ao passar o mouse sobre uma linha, ela deve mudar de cor.
    • Ao clicar em uma linha, ela deve ficar selecionada.
    • Deve exibir a mensagem: “Linha X selecionada”.
    • Apenas uma linha pode ficar selecionada por vez.
    • O cursor deve mudar para “pointer” ao passar sobre as linhas.

Tabela com Ordenação

  • Requisito: Permitir ordenar colunas em ordem crescente e decrescente.
  • Critérios de aceite:
    • As colunas devem exibir setas de ordenação (▲▼).
    • Ao clicar no cabeçalho, a coluna deve alternar entre crescente e decrescente.
    • O cursor deve mudar para “pointer” ao passar sobre o cabeçalho.
    • O cabeçalho deve ter leve destaque visual ao passar o mouse.
    • A ordenação deve refletir imediatamente na tabela.
    • O espaçamento entre o texto e as setas deve estar adequado.

Tabela com Busca

  • Requisito: Permitir filtrar os dados digitando no campo de busca.
  • Critérios de aceite:
    • Deve existir um campo de busca acima da tabela.
    • A busca deve filtrar dinamicamente conforme o usuário digita.
    • O filtro deve considerar todas as colunas da tabela.
    • Ao limpar o campo, a tabela deve voltar ao estado original.
    • Deve exibir a mensagem: “X resultados encontrados”.
    • Não deve haver travamentos ou atrasos perceptíveis.

Tabela com Paginação

  • Requisito: Permitir navegar entre páginas de conteúdo.
  • Critérios de aceite:
    • A tabela deve exibir apenas os itens da página atual.
    • Os botões de navegação devem permitir avançar e retornar páginas.
    • A página atual deve ser destacada visualmente.
    • Ao avançar, deve exibir: “Página avançada com sucesso”.
    • Ao retornar, deve exibir: “Página retornada com sucesso”.
    • O número da página deve estar centralizado entre os botões.

Tabela com Seleção de Linhas

  • Requisito: Permitir selecionar linhas usando checkboxes.
  • Critérios de aceite:
    • Cada linha deve possuir um checkbox na primeira coluna.
    • O checkbox deve estar alinhado vertical e horizontalmente.
    • Ao marcar uma linha, ela deve ganhar destaque visual.
    • Deve exibir a mensagem: “X linhas selecionadas”.
    • O checkbox do cabeçalho deve selecionar/deselecionar todas as linhas.
    • O estado visual deve refletir corretamente a seleção.

Tabela com Ações

  • Requisito: Permitir executar ações específicas por linha.
  • Critérios de aceite:
    • Cada linha deve possuir botões de ação (Editar, Excluir, etc.).
    • Os botões devem estar centralizados na coluna de ações.
    • Ao clicar em um botão, deve exibir a mensagem correspondente.
    • As ações não devem interferir nas outras tabelas.
    • Os botões devem possuir tooltip (title) quando aplicável.

Estado Vazio

  • Requisito: Exibir mensagem adequada quando não houver dados.
  • Critérios de aceite:
    • A tabela deve exibir uma linha única com a mensagem: “Nenhum registro encontrado”.
    • A mensagem deve estar centralizada horizontalmente.
    • Não deve exibir cabeçalhos de ações ou checkboxes quando não houver dados.
    • Não deve quebrar o layout da página.

Acessibilidade

  • Avatar VLibras deve estar disponível em todas as páginas.
  • Botão de Leitura em Áudio deve estar disponível no canto superior direito.
  • Todos os botões devem possuir atributos aria-label descritivos.
  • Mensagens de erro e sucesso devem ser anunciadas pelo recurso de áudio.
  • Todos os modais devem ser acessíveis por teclado, leitura em áudio e VLibras.
