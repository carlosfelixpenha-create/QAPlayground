Requisitos 'Quebra-Cabeça 104 Peças'

Campos

Tabuleiro

  • Requisito: Exibir 104 peças embaralhadas.
  • Critérios de aceite:
    • As peças devem ser arrastáveis (drag & drop).
    • O jogador deve conseguir trocar posições entre peças.
    • O tabuleiro deve usar o layout horizontal (13 × 8).
    • Ao montar corretamente, deve exibir mensagem de vitória em uma modal rápida.
    • Mensagem exibida: “🎉 Parabéns, você montou o quebra-cabeça!”.

Imagem de Referência

  • Requisito: Exibir a imagem completa do quebra-cabeça.
  • Critérios de aceite:
    • A imagem deve ser exibida ao lado direito do tabuleiro.
    • Deve usar estilo exclusivo (.referencia104pcs) para não afetar outros níveis.

Botões

Requisitos

  • Requisito: Redireciona para esta tela de requisitos.
  • Critério de aceite: Ao clicar, deve carregar quebra-cabeca-104pcs-requisitos.html.

Voltar

  • Requisito: Redireciona para a tela Home.
  • Critério de aceite: Ao clicar, deve carregar home.html.

Embaralhar

  • Requisito: Disponível apenas após o jogador montar corretamente o quebra-cabeça.
  • Critérios de aceite:
    • Botão deve permanecer desabilitado até a vitória.
    • Ao clicar, deve embaralhar novamente as peças do tabuleiro.
    • Após embaralhar, o botão volta a ficar desabilitado até a próxima vitória.
    • Ao embaralhar, deve exibir uma modal rápida com a mensagem “Tabuleiro embaralhado!”.

Acessibilidade

  • Avatar VLibras deve estar disponível em todas as páginas.
  • Botão de Leitura em Áudio deve estar disponível no canto superior direito.
  • Todos os botões devem possuir atributos aria-label descritivos.
  • Mensagens de erro e sucesso devem ser anunciadas pelo recurso de áudio.
  • Todos os modais devem ser acessíveis por teclado, leitura em áudio e VLibras.
