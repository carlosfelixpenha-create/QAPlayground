Requisitos 'Tela de Cadastro'

Campos

Observação: Todos os campos obrigatórios devem ser identificados com asterisco (*) no label.

Nome*

  • Requisito: Deve permitir digitar nome completo (mínimo 3 caracteres, nome e sobrenome).
  • Critérios de aceite:
    • Campo não pode estar vazio.
    • Deve conter pelo menos nome e sobrenome.
    • Não deve aceitar números ou caracteres especiais.
    • Campo não permite dois espaços seguidos.
    • Mínimo 3 caracteres para nome.
    • Mínimo 3 caracteres para sobrenome.
    • Mínimo 7 caracteres para o campo nome.
    • Máximo 64 caracteres para o campo nome.
    • Exibir mensagem de erro em modal se não atender às regras.
    • Mensagem exibida: “Preencher corretamente o campo Nome, dúvida entrar em Requisitos!”

E-mail*

  • Requisito: Deve permitir digitar um e-mail válido.
  • Critérios de aceite:
    • Campo não pode estar vazio.
    • Deve conter “@” e domínio válido.
    • Não deve permitir espaços em branco.
    • Máximo 64 caracteres para o campo e-mail.
    • Exibir mensagem de erro em modal se não atender às regras.
    • Mensagem exibida: “Preencher corretamente o campo E-mail, dúvida entrar em Requisitos!”

Senha*

  • Requisito: Deve permitir digitar senha (mínimo 6 caracteres).
  • Critérios de aceite:
    • Campo não pode estar vazio.
    • A senha precisa ter no mínimo um número.
    • A senha precisa ter no mínimo uma letra maiúscula.
    • A senha precisa ter no mínimo um caractere especial.
    • A senha precisa ter no mínimo 6 caracteres.
    • A senha precisa ter no máximo 12 caracteres.
    • Deve ocultar os caracteres digitados (tipo password).
    • Deve mostrar os caracteres digitados ao clicar no ícone mostrar senha.
    • Exibir mensagem de erro em modal se não atender às regras.
    • Mensagem exibida: “Preencher corretamente o campo Senha, dúvida entrar em Requisitos!”

Confirmar Senha*

  • Requisito: Deve validar se a senha digitada é igual ao campo Senha.
  • Critérios de aceite:
    • Campo não pode estar vazio.
    • Os caracteres do campo Confirmar Senha devem ser idênticos aos do campo Senha.
    • Exibir mensagem de erro em modal se não atender às regras.
    • Mensagem exibida: “As senhas não conferem, dúvida entrar em Requisitos!”

Botões

Cadastrar

  • Requisito: Executa a validação dos campos e simula cadastro.
  • Critérios de aceite:
    • Se todos os campos estiverem corretos, exibir mensagem de sucesso em modal com botão OK.
    • Mensagem exibida: “Cadastro realizado com sucesso!”.
    • Não deve permitir cadastro com campos vazios.
    • Se inválidos, exibir mensagem de erro clara em modal, por campo.
    • Após sucesso, exibir botões de QA e limpar os campos do formulário.
    • Após sucesso, os campos de cadastro e o botão “Cadastrar” devem ser desabilitados até que o usuário clique em “Limpar Cadastro”.
    • O cadastro realizado deve ser armazenado no localStorage e utilizado como pré-cadastro para a tela de Login.

Voltar

  • Requisito: Redireciona para a tela Home.
  • Critério de aceite: Ao clicar, deve carregar home.html.

Requisitos

  • Requisito: Redireciona para a tela de requisitos.
  • Critério de aceite: Ao clicar, deve carregar cadastro-requisitos.html.

QA - Ver Usuário Salvo

  • Requisito: Exibe os dados do usuário armazenados no localStorage.
  • Critério de aceite: Ao clicar, deve mostrar em modal os dados salvos (Nome e Email) ou mensagem de ausência. A modal deve conter botão OK para fechar.

QA - Limpar Cadastro

  • Requisito: Remove o usuário armazenado no localStorage.
  • Critério de aceite:
    • Ao clicar, deve apagar os dados, limpar os campos do formulário e ocultar novamente os botões de QA.
    • Após limpar, os campos e o botão “Cadastrar” devem ser reabilitados para permitir novo cadastro.
    • A modal deve conter botão OK para fechar.

Acessibilidade

  • Avatar VLibras deve estar disponível em todas as páginas.
  • Botão de Leitura em Áudio deve estar disponível no canto superior direito.
  • Todos os botões devem possuir atributos aria-label descritivos.
  • Mensagens de erro e sucesso devem ser anunciadas pelo recurso de áudio.
  • Todos os modais devem ser acessíveis por teclado, leitura em áudio e VLibras.
