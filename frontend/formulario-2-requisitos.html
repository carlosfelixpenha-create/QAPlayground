Requisitos 'Formulário 2 - Campos Diversos'

Campos

Observação: Todos os campos obrigatórios devem ser identificados com asterisco (*) no label.

Sexo*

  • Requisito: Deve permitir selecionar apenas uma opção (Masculino ou Feminino).
  • Critérios de aceite:
    • Campo não pode estar vazio.
    • Deve aceitar apenas uma opção marcada.
    • Mensagem exibida: “Preencher corretamente o campo Sexo, dúvida entrar em requisitos!”

Interesses*

  • Requisito: Deve permitir selecionar uma ou mais opções (Frontend, Backend, QA).
  • Critérios de aceite:
    • Campo não pode estar vazio.
    • Deve ter pelo menos uma opção marcada.
    • Mensagem exibida: “Selecione ao menos uma opção em Interesses, dúvida entrar em requisitos!”

Data de Nascimento*

  • Requisito: Deve permitir selecionar uma data válida.
  • Critérios de aceite:
    • Campo não pode estar vazio.
    • Não deve aceitar datas futuras.
    • Usuário deve ter idade mínima de 16 anos.
    • Mensagens exibidas: - “Preencher corretamente o campo Data de Nascimento, dúvida entrar em requisitos!” - “Data de Nascimento não pode ser futura!” - “Idade mínima permitida é de 16 anos!”

Telefone*

  • Requisito: Deve permitir digitar telefone no formato (99) 99999-9999.
  • Critérios de aceite:
    • Campo não pode estar vazio.
    • Não deve aceitar letras ou caracteres fora do padrão.
    • Deve validar o formato correto.
    • Mensagens exibidas: - “Preencher corretamente o campo Telefone, dúvida entrar em requisitos!” - “Telefone inválido! Use o formato (99) 99999-9999.”

CPF*

  • Requisito: Deve permitir digitar CPF no formato 999.999.999-99.
  • Critérios de aceite:
    • Campo não pode estar vazio.
    • Deve conter 11 dígitos válidos.
    • Deve validar o formato correto.
    • Mensagens exibidas: - “Preencher corretamente o campo CPF, dúvida entrar em requisitos!” - “CPF inválido! Use o formato 999.999.999-99.”

Botões

Enviar

  • Requisito: Executa a validação dos campos e simula envio do formulário.
  • Critérios de aceite:
    • Se todos os campos obrigatórios estiverem corretos, exibir mensagem de sucesso em modal com botão OK.
    • Mensagem exibida: “Formulário enviado com sucesso!”.
    • Não deve permitir envio com campos obrigatórios vazios.
    • Se inválidos, exibir mensagem de erro clara em modal, por campo.
    • Após sucesso, os campos devem ser limpos automaticamente para permitir novo preenchimento.

Voltar

  • Requisito: Redireciona para a tela Home.
  • Critério de aceite: Ao clicar, deve carregar home.html.

Requisitos

  • Requisito: Redireciona para a tela de requisitos.
  • Critério de aceite: Ao clicar, deve carregar formulario-2-requisitos.html.

Acessibilidade

  • Avatar VLibras deve estar disponível em todas as páginas.
  • Botão de Leitura em Áudio deve estar disponível no canto superior direito.
  • Todos os botões devem possuir atributos aria-label descritivos.
  • Mensagens de erro e sucesso devem ser anunciadas pelo recurso de áudio.
  • Todos os modais devem ser acessíveis por teclado, leitura em áudio e VLibras.
